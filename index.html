[ 指引怎麼說 ]

英國 NICE 失智照護指引（NG97, 2018）建議：提供依個人喜好量身安排的各種活動，來維持身心安適。活動是最基本、也最先做的非藥物照護。

居服員每週來的那幾個小時，可能是長輩一週裡最有機會「做點事」的時間。

活動，藏在你本來就在做的服務裡

[ BA02 ]

梳頭、穿衣、刷牙時，讓長輩自己做能做的那一步，就是活動。

[ BA11 ]
肢體關節活動

下半場的主角。關節活動與坐姿運動，可以配音樂、配數數。

[ BA18 ]

看著他不出事之外，也可以一起摺衣服、看老照片。

[ BA20 ]
陪伴服務

最適合放進有安排的活動：聊天、唱歌、桌上活動、散步。

實際能做的項目與時間，以個案的照顧計畫和督導的安排為準；有疑問先問督導，不要自己加項目。

先看他還會什麼

同一個「摺衣服」，輕度的人可以自己摺完放進衣櫃，重度的人可能只能摸毛巾、對摺一次。活動要跟著能力走。

    BA11 肢體關節活動：做與不做

    [ 居服員的範圍 ]
    [ 做 ]
    • 依照顧計畫，協助各關節做全範圍的活動
    • 陪長輩做坐姿運動、站起來練習
    • 做之前看狀況，做之中看表情
    • 記下次數、疼痛、異常，回報督導
    • 把治療師教的居家動作，照樣陪他做
    [ 不做 ]
    • 硬扳到會痛、聽到聲音還繼續
    • 處理紅、腫、熱、痛的關節
    • 骨折、剛開刀處，沒有醫囑就動
    • 自己加新的「治療」動作或按摩手法
    • 長輩明確拒絕時還堅持要做

    不確定能不能做，就先不做，回報督導，請治療師（如居家復能、專業服務）來評估。

    手怎麼放？五個原則

    [ 每個動作 5–10 下 ]
    [ 01 ]托上、托下

    一手托關節上方、一手托下方，讓整段肢體被撐住，不要只拉手腕或腳踝。

    [ 02 ]慢慢來

    去程數 1、2、3，回程也數 1、2、3。快速甩動容易拉傷。

    [ 03 ]到緊，不到痛

    感覺有阻力、他說「緊」就停在那裡，停 2–3 秒再回來。

    [ 04 ]看臉不看手

    眼睛看他的表情。皺眉、縮手、叫出聲，馬上減少範圍。

    [ 05 ]先說再動

    「我要把妳的手抬起來喔。」失智長輩被突然碰到會害怕、會抗拒。

    接下來七頁是仰躺的關節活動。● 綠點是你的手要托的位置。

    這三種情況，特別小心

    [ 有治療師的指示，就照指示 ]
    [ 中風・偏癱的肩膀 ]
    不拉、不甩、不硬舉
    • 不要拉患側的手把人拉起來或翻身
    • 舉手時一手托住肩胛骨，讓肩胛跟著轉
    • 只做到不痛的範圍；肩膀已經痛，請治療師評估
    • 平常把患側手臂放在枕頭上撐好
    [ 人工髖關節 ]
    手術後依醫囑
    • 常見的提醒：彎曲不超過 90°
    • 腿不交叉、不越過身體中線
    • 膝蓋和腳尖朝上，不往內轉
    • 不同手術方式限制不同，照醫院給的衛教單
    [ 骨質疏鬆・失智 ]
    輕、慢、先說
    • 骨鬆：不扭轉、不用力壓、不硬扳
    • 失智：先說、再示範、才動手
    • 他抗拒時停下來，換時間或換方式
    • 疼痛說不清楚，看表情與縮手

    [ 帶失智長輩運動 ]

    不要說「運動」，說「幫我」

    [ 一起動 ]
    [ 01 ] 面對面示範

    坐在他正前方，像照鏡子一樣做，他跟著學。

    [ 02 ] 一次一個指令

    「腳抬起來」做完，再說「放下」。不要一次講三件事。

    [ 03 ] 數數、唱歌

    用他熟悉的歌打拍子，一首歌就是一組。

    [ 04 ] 做完說謝謝

    「你好有力氣，謝謝你幫忙。」讓他下次還願意。
