    失智的阿嬤一整天安安靜靜坐著看電視，這樣好嗎？

    點右邊選一個答案，先舉手投票也可以。
    正確答案：B
    沒事做，是失智照顧裡最常被忽略的問題

    整天被動坐著：白天睡、晚上醒，能力用不到就退得快，到了傍晚焦慮更明顯。接下來兩小時，就是學怎麼讓他「有事做」。

    [ 為什麼 ] 活動不是加分題

    沒事做的一天，最難熬

    [ 沒事做 ]

    無聊、孤單、聽不懂

    一天坐著看電視、不知道現在要做什麼

    [ 就會出現 ]

    躁動、遊走、重複問

    吵著回家、翻東西、黃昏特別不安

    [ 指引怎麼說 ]

    英國 NICE 失智照護指引（NG97, 2018）建議：提供依個人喜好量身安排的各種活動，來維持身心安適。活動是最基本、也最先做的非藥物照護。

    居服員每週來的那幾個小時，可能是長輩一週裡最有機會「做點事」的時間。

    活動，藏在你本來就在做的服務裡

    [ 長照 2.0 照顧組合 ]
    [ BA02 ]
    基本日常照顧

    梳頭、穿衣、刷牙時，讓長輩自己做能做的那一步，就是活動。

    [ 例如 ]
    • 梳子交到他手上，你只扶手肘
    • 先遞袖子，讓他自己把手穿進去
    • 牙膏擠好，他自己刷前面
    [ BA11 ]
    肢體關節活動

    下半場的主角。關節活動與坐姿運動，可以配音樂、配數數。

    [ 例如 ]
    • 配一首〈望春風〉，跟著拍子做
    • 邊做邊數 1 到 10，請他一起數
    • 做完問：「哪裡比較鬆？」
    [ BA18 ]
    安全看視

    看著他不出事之外，也可以一起摺衣服、看老照片。

    [ 例如 ]
    • 一起摺毛巾、撿菜、剝豆子
    • 翻相簿，聊照片裡的人
    • 他動手做，你在旁邊顧安全
    [ BA20 ]
    陪伴服務

    最適合放進有安排的活動：聊天、唱歌、桌上活動、散步。

    [ 例如 ]
    • 散步順路看街景、買個菜
    • 撲克牌配對、唱年輕時的歌
    • 用時光留聲機錄下他的故事

    實際能做的項目與時間，以個案的照顧計畫和督導的安排為準；有疑問先問督導，不要自己加項目。

    先看他還會什麼

    同一個「摺衣服」，輕度的人可以自己摺完放進衣櫃，重度的人可能只能摸毛巾、對摺一次。活動要跟著能力走。

    你陪，
    他主導
    還會

    備餐、園藝、記帳、唱歌、桌遊、散步買東西
    你的角色
    給選擇、留時間，別替他做
    [ 中度 ]
    你帶，
    他跟著做
    還會
    熟悉的單一動作：擦、摺、撿、搓、配對；舊歌和舊事
    適合
    撿菜、摺毛巾、配襪子、老照片、拍手唱歌
    你的角色
    拆成一步一步，一次只給一個指令
    [ 重度 ]
    你給，
    他感受
    還會
    感覺仍在：觸覺、聲音、味道、被握住的手
    適合
    手部按摩、聽熟悉的歌、聞香、握柔軟的布、曬太陽

    慢、輕、靠近，看表情決定要不要繼續
    [ 四個原則 ] 每次安排前，在心裡過一遍
    [ 01 ]
    用他
    還會的

    從以前的工作、拿手的家事開始，不從「新東西」開始。

    [ 02 ]
    拆成
    小步驟

    做成功

    對待

    [ 生命故事 × 聊天錄音 ] 時光留聲機

    陪他聊，順便錄成一張唱片

    生命故事卡是寫下來；時光留聲機是把長輩自己說的故事錄起來。錄音只存在這支手機，不會上傳。

    1. 選一段人生（童年、工作、成家⋯），點一題問題
    2. 按「開始錄音」，慢慢問、等他想；停住就點「追問小卡」

      先看身體，再找對的輔具

      活動和生活排得再好，做不到的那一步，有時候是缺一個工具。依身體狀況查，就能找到對應的輔具與補助。

      [ 開場這樣說 ]

      「阿嬤，我是小美，今天禮拜天，外面出太陽喔。」先叫名字、說自己是誰、說今天。

      [ 主活動 ]

      只做一件事，照前面的難度調整。看他的臉：笑、專心就延長；皺眉、想走就換。

      [ 收尾 ]

      「今天妳摺了 8 條毛巾，好整齊，謝謝妳幫忙。」說出他做到的事。

      寫下做了什麼、做多久、心情、需要哪一格提示，給督導和下一位同事。

      [ DICE 模式 ] Kales 等人，2014
      D
      描述

      什麼時候、在哪裡、做了什麼、持續多久？拍照或寫下來。
      例：每天 16:00 後在門口走，約 40 分鐘。

      I
      找原因

      身體（痛、便祕、想上廁所）、環境（太吵、太暗）、作息、需求沒被滿足。
      例：以前這個時間在備料。

      C
      想辦法

      跟家屬、督導一起想，給一件有意義的事來代替。
      例：15:45 先安排撿菜、擺碗筷。

      E

      [ Q&A 01 ] 被動關節運動

      被動關節運動，可以增加肌力嗎？

      先舉手：覺得可以的舉 O，不行的舉 X，再按答案。
      X 不行。肌肉沒有自己用力，就不會變強。
      [ 為什麼 ]

      肌力要靠肌肉自己收縮、而且要「有點累」才會進步。被動時是你在出力，他的肌肉是放鬆的。

      [ 那它在做什麼 ]

      減少僵硬、讓關節保持能動的範圍、促進血液循環，也讓你每天摸得到他的關節有沒有變化。

      [ 想保住肌力 ]

      他能出一點力，就改成協助主動：「你先舉，我幫你」。能坐，就練坐到站。

      肌力訓練原則參考 WHO 2020 身體活動指引（每週 2 天以上、有點累）。

      [ Q&A 02 ] 被動關節運動

      被動關節運動，可以讓關節角度變大嗎？

      先舉手：覺得可以的舉 O，不行的舉 X，再按答案。
      X 幾乎不行。它的重點是「維持」，不是「變大」。
      [ 研究怎麼說 ]

      Cochrane 系統性回顧整理數十篇牽拉研究：規律牽拉對關節活動度的改善只有幾度，臨床上幫助不大。

      [ 所以每天做 ]

      是為了「不要再變緊」：沒動的關節幾天到幾週就開始卡住，每天動一動，把現在的角度留住。

      [ 已經卡住了 ]

      手伸不直、腳尖下垂、手指握拳打不開：不要硬扳，回報督導，請治療師評估擺位、副木。

      1. 坐到椅子前半，腳往後收到膝蓋正下方
      2. 身體往前傾，「鼻子超過腳尖」
      3. 腳踩地站起來，站直、眼睛看前面
      4. 屁股往後找椅子，數 1、2、3 慢慢坐下
      [ 減難度 ]

      用高一點的椅子、雙手扶扶手

      [ 加難度 ]

      雙手抱胸、坐下時放慢到 3 秒

      為什麼上廁所、上床、出門都要站起來；美國 CDC 防跌評估 STEADI 也用「30 秒坐站」。

      站不穩時，坐著先打底

      [ 肌力 02–07 ] 打底用，最後要回到生活動作
      [ 學習檢核 2 / 2 ] 肌力訓練

      阿公坐到站做了 10 下，說累的程度只有「2」。下次怎麼調？

      有點累（5 左右），才剛好

      0–10 的累，2 代表太輕鬆。WHO 建議長者每週 2 天以上、8–12 下 × 1–3 組，做輕鬆就加：先加次數，再加重量。

      [ 椅子 ]

      靠牆放、不會滑的椅子，不要用有輪子的辦公椅。

      [ 重量 ]

      能做 12 下還輕鬆才加重；手腕無力的人用毛巾包住瓶子比較好握。

      [ 收好 ]

      失智長輩做完，彈力帶、小物品收起來，避免纏繞或誤食。

      [ 帶失智長輩運動 ]

      不要說「運動」，說「幫我」

      「阿公，幫我把杯子拿過去。」站起來、走兩步、坐下，就是一組坐到站。

      [ 一起動 ]
      [ 01 ] 面對面示範

      坐在他正前方，像照鏡子一樣做，他跟著學。

      [ 02 ] 一次一個指令

      「腳抬起來」做完，再說「放下」。不要一次講三件事。

      [ 03 ] 數數、唱歌

      用他熟悉的歌打拍子，一首歌就是一組。

      [ 04 ] 做完說謝謝

      「你好有力氣，謝謝你幫忙。」讓他下次還願意。

      合起來：動腦＋動手30 分鐘

      5′打招呼、今天幾號、量血壓前坐好

      8′生活活動：撿四季豆、擺碗筷，備晚餐
      4′收尾聊天、記錄
      [ 為什麼這樣排 ]

      先動身體讓精神好，再做她熟悉的備料，剛好接上她以前 16:00 的習慣，減少黃昏想回家。
